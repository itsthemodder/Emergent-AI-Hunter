the flow

One manager, many hunters

The file structure goes something like: main.js runs the tick loop, which calls hunterManager.js to spawn and track bots, which hands each one to hunter.js to decide what it does — pulling logic from a behaviors/ folder (combat, pathfinding, survival, gathering, fishing, teleport), with gear handled in gearUtils.js and every tunable number kept in one place, data.js.

main.js→hunterManager.js→hunter.js→behaviors/*→gearUtils.js

setup

Install it

1
Make a world

New world, survival or creative — ideally superflat, so it's easy to actually watch the bots path and fight.

2
Turn on all experimental toggles

The pack runs on Beta APIs and GameTest under the hood — safest to just flip every experimental toggle on before creating the world.

3
Apply the behavior pack

Import the .mcpack, then add it under the world's Behavior Packs.

4
Load in as an operator

The commands need Game Directors permission — make sure you're host or have op.

5
Spawn your first hunter

Run /spawnor /ai:spawn and see what comes for you.
